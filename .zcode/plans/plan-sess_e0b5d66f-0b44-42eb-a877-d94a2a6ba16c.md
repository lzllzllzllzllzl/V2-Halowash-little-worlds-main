## 主页背景改造:黑白灰写实小街区(仅主页,场景详情页不动)

### 1. 重写背景模块 src/hw-backdrop.js(把之前星空版全部替换)
- **阴天渐变天空**:浅灰地平线 → 稍深的灰白天顶,干净中性,无彩色
- **灰色雾效**:与地平线同色,让地面边缘自然融进天际(写实纵深)
- **程序化街区地面**(2048px 画布贴图):中灰沥青底 + 十字主干道(深灰路面、白色车道虚线、路口斑马线、浅灰路缘石线),四座建筑分列四个象限
- **远处城市剪影**:一圈随机高度的灰色低多边形楼房(约 40 栋),被雾柔化成剪影,随镜头旋转视差正确,增强"城市里"的感觉

### 2. 调整 src/hw-index.js
- 换用新背景模块;灯光去暖去蓝(白色主光 + 中性灰环境光),匹配黑白灰氛围
- 真实地面接收建筑阴影(替换现在的隐形接影板);每座建筑下加浅灰混凝土台基,跟随布局移动
- 取消四座建筑的上下漂浮(落地感),名牌轻微浮动保留;旋转、点击进入等交互全部不变

### 3. index.html 浅色适配
- body/loading 背景改浅灰、去掉深蓝 vignette 暗角、theme-color 同步
- bundle 版本号升到 v=14(强制刷新缓存)

### 4. 构建与上线
- `node tools/build-bundle.mjs` 重新构建
- 本地 `python -m http.server` + 浏览器截图验证、微调(对比度/雾浓淡/路面标线粗细)
- git 提交推送到 GitHub Pages,线上复验截图给你确认

颜色基调:天空 #d5dade → #aeb4bc,地面沥青 #878c90、马路 #6b7075、台基 #c2c6ca,全部黑白灰,黑色名牌和青色描边作为少量点缀保留。
